# Rafa Play 🪐

Reproductor de música para Android con estética **Mars UI** y diseño minimalista AMOLED.

### Características

- **Estética Mars UI:** Cápsula curvada adaptable (modo cápsula / modo cuadrado) y paleta dinámica según la carátula.
- **Seekbar en Arco Curvo:** Barra de reproducción circular integrada en el contorno de la carátula.
- **Cola Orbital de Planetas (PlanetQueue):** Sistema visual interactivo con órbitas celestiales para explorar las siguientes pistas.
- **Paleta Superior Curvada:** Banner de control que desciende desde la parte superior al reproducir.
- **Diseño Minimalista de Líneas:** Iconografía de líneas simples sin saturación visual.
- **Navegación Esencial:** Pestañas directas de Canciones y Listas de reproducción, con búsqueda en tiempo real.
- **Servicio en Primer Plano:** Reproducción continua optimizada para Android 14+ con MediaSession y soporte para pantalla de bloqueo.

### Arquitectura

- **Paquete:** `com.rafa.play`
- **Lenguaje:** Java 17 / Android SDK 34
- **UI:** Material Components, Canvas personalizado, Palette API, ViewPager2
